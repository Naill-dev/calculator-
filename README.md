# 🧮 Alpha Calculator

> A sleek, modern web calculator built with **Vanilla JavaScript**, **HTML5**, and **CSS3**. Features a glassmorphic dark interface, real-time expression rendering, and full keyboard interaction support.

![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)

🔗 **Live Demo:** [naill-dev.github.io/calculator-](https://naill-dev.github.io/calculator-/)

---

## ✨ Features

- ➕ **Core Operations:** Addition, subtraction, multiplication, and division with standard precedence.
- ⌨️ **Full Keyboard Support:** Complete mapping for numbers, operators, `Enter`, `Backspace`, `Esc`, and decimals.
- 🧮 **Live Expression Line:** Displays the full input string alongside live evaluation results.
- 🛡️ **Edge Case Handling:** Prevents division by zero and invalid decimal chaining.
- 🎨 **Glassmorphism UI:** Modern dark mode interface styled with CSS backdrop blurs and smooth transitions.
- 📱 **Fully Responsive:** Adaptive grid system designed for mobile and desktop displays.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic Structure)
- **Styling:** CSS3 (Flexbox/Grid, Custom CSS Variables, Glassmorphism)
- **Logic:** Vanilla JavaScript (ES6+)

---

## 🚀 Getting Started

No external dependencies or build tools required.

### Installation & Local Run

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Naill-dev/calculator-.git](https://github.com/Naill-dev/calculator-.git)
   cd calculator-

```

2. **Launch the project:**
Simply double-click `index.html` to open it in your default browser, or serve it locally:
```bash
npx serve .

```

## ⌨️ Keyboard Shortcuts

| Key | Action |
| --- | --- |
| `0` – `9` | Input Digits |
| `+`, `-`, `*`, `/` | Arithmetic Operators |
| `Enter` or `=` | Calculate Result |
| `Backspace` | Delete Last Character |
| `Esc` | Clear All (AC) |
| `.` | Add Decimal Point |
| `%` | Calculate Percentage |
