# 🧮 Alpha Calculator

> A sleek and modern web calculator built with **Vanilla JavaScript**, **HTML5**, and **CSS3**. Features a glassmorphic dark interface, real-time expression rendering, and full keyboard support.

## ✨ Features

- ➕ Basic arithmetic operations (+, −, ×, ÷)
- ⌨️ Full keyboard support
- 🧮 Real-time expression display
- 🛡️ Division-by-zero protection
- 🎨 Modern glassmorphism UI
- 📱 Fully responsive design

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **Vanilla JavaScript (ES6+)**

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Naill-dev/calculator-.git
cd calculator-
```

### Run Locally

Open `index.html` in your browser or use:

```bash
npx serve .
```

## ⌨️ Keyboard Shortcuts

| Key | Action |
|------|--------|
| 0-9 | Input Digits |
| + - * / | Operators |
| Enter or = | Calculate |
| Backspace | Delete Last Character |
| Esc | Clear All |
| . | Decimal Point |
| % | Percentage |
